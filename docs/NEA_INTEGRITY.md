# NEA Integrity Policy

Neat Notes supports learning about programming-project principles but must not generate assessed H446 project submissions.

## Allowed

- explaining generic programming concepts;
- debugging small generic examples;
- teaching analysis, design, testing and evaluation terminology;
- explaining test strategies and development methods;
- revision questions about the NEA process;
- integrity guidance for students and teachers.

## Not Allowed

- candidate-specific report sections;
- a complete candidate-specific design or evaluation;
- substantial candidate-specific project code intended for submission;
- fabricated tests, evidence or evaluation results;
- rewriting assessed work to disguise authorship.

Component 03/04 is represented in the content model as `integrity_guidance_only`. No unfinished NEA generator or candidate-work assistant is exposed in the product. Any future assistance must use least-help-first scaffolding, be clearly labelled, and be reviewed against current OCR and centre policy before release.
